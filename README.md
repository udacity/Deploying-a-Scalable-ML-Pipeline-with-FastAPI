# Deploying a Scalable ML Pipeline with FastAPI

This project demonstrates how to build, test, and deploy a machine learning pipeline using **FastAPI**.  
It includes:
- Data preprocessing with scikit-learn
- Model training and inference
- RESTful API endpoints for predictions
- Automated testing with pytest
- Continuous Integration via GitHub Actions

---

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- Virtual environment (`venv` or similar)
- Dependencies listed in `requirements.txt`

### Installation
```bash
git clone https://github.com/NikhilShetty-45/Deploying-a-Scalable-ML-Pipeline-with-FastAPI.git
cd Deploying-a-Scalable-ML-Pipeline-with-FastAPI.git
python -m venv .venv
source .venv/bin/activate   # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
